HOW IT WORKS

关于加密

你的密码用 PBKDF2-SHA256 派生出一把钥匙，再用它打开一把随机生成的主密钥。所有日记正文都由主密钥以 AES-256-GCM 加密。

加密后的内容会写进你自己的 GitHub 仓库，所以就算仓库是公开的，别人也只能看到一串密文。

密码只存在于当前页面的内存中。关掉页面或自动上锁后，它就会被清空。

但请记得：如果忘记密码，没有任何办法恢复日记。这是加密的代价，也是它的承诺。
