ONE-TIME SETUP

配置加密同步

整个过程大约需要三分钟。配置完成后，这本网页日记就真正属于你了。

01

设定一把钥匙

这将是以后每次打开日记时输入的密码。

请务必备份密码。日记会用这把密码加密。忘记密码时，没有任何人、任何服务可以帮你找回。

02

连接 GitHub 仓库

日记密文会通过 GitHub API 写进这个仓库。

配置config.json
日记data/diary.enc.json
03

写入并开始

会创建一份空的加密日记和配置文件。

点击后会把加密后的 config.json 与空日记写入仓库。GitHub Pages 通常需要一小会儿重新部署。

也可以手动放入仓库

下载这两个文件，按对应路径上传到仓库即可。配置文件必须最后上传。

Δ

ALL SET

钥匙已经放好了

配置文件和加密日记已经写入 你的仓库。等 GitHub Pages 完成部署后，回到首页，输入刚才的密码，就可以翻开第一页。

去打开日记 查看 config.json

建议把配置文件另存一份。它不包含明文密码，但仍应妥善保管。
